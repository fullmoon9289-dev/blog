# 네이버 블로그 자동화

> ### 👉 윈도우에서 처음 켜시나요?
> 컴퓨터를 잘 모르셔도 따라 할 수 있게 적어둔 **[설치안내-윈도우.md](설치안내-윈도우.md)** 를 보세요.
> 아래 내용은 개발을 아는 분을 위한 요약입니다.

관심 분야를 넣으면 **AI 가 글감을 찾고 → 글을 쓰고 → 사진을 구하거나 만들고 →
네이버 블로그 에디터에 직접 타이핑해 발행까지** 하는, 내 컴퓨터에서만 도는 웹앱입니다.

## 시작하기

### 1. 준비물 확인

명령어를 입력하는 창을 열고(맥: `Command + 스페이스` → "터미널" / 윈도우: 시작 → "터미널"),
아래를 붙여넣고 엔터를 누르세요.

```bash
node --version && claude --version
```

숫자 두 줄이 나오면 준비 끝입니다.
안 나온다면 [Node.js](https://nodejs.org) 와 [Claude Code](https://claude.com/claude-code) 를 먼저 설치하세요.

### 2. 필요한 프로그램 내려받기

```bash
npm install
```

### 3. 앱 켜기

```bash
npm run dev
```

브라우저에서 **http://localhost:4123** 을 여세요.
⚠️ 이 창은 켜둔 채로 두세요. 닫으면 앱이 꺼집니다.

### 4. 네이버 로그인 (발행 전에 한 번)

화면 위쪽 **[네이버 로그인]** 을 누르면 새 창이 뜹니다. 평소처럼 로그인하세요.

> **"로그인 상태 유지"에 꼭 체크해 주세요.**
> 안 하면 몇 시간 뒤 다시 로그인해야 하고, 읽기는 되는데 글쓰기만 막히는 헷갈리는 상태가 됩니다.

아이디와 비밀번호는 이 앱이 다루지 않습니다. 창에서 직접 입력하시고, 앱은 로그인된 상태만 저장합니다.

### 5. (선택) AI 로 사진 만들기

**안 하셔도 앱은 전부 동작합니다.** 사진을 검색해서 가져오거나 직접 찍은 사진을 쓰면 됩니다.

```bash
cp env.sample .env.local     # 윈도우: copy env.sample .env.local
```

`.env.local` 을 열어 [Cloudflare](https://dash.cloudflare.com) 의 계정 ID 와 API 토큰을 넣으세요.
**값을 넣은 뒤에는 앱을 껐다 다시 켜야 반영됩니다.**

## 안전장치

처음 켜면 **연습 모드**입니다. 글을 에디터에 넣어보고 완성 화면만 저장할 뿐, 실제로 올라가지 않습니다.

| 장치 | 기본값 |
|---|---|
| 연습 모드 | **켜짐** |
| 공개 범위 | **비공개** |
| 하루 발행 수 | 3편 |
| 최소 발행 간격 | 30분 |
| 전체 중단 | 꺼짐 |

실제로 올리려면 설정에서 연습 모드를 끄세요. **여기서부터는 되돌릴 수 없습니다.**
처음에는 비공개로 올려 어떻게 나오는지 확인하시길 권합니다.

## 알아두실 점

- **자동 발행은 네이버 이용약관상 계정 제재 위험이 있습니다.** 그래서 위 안전장치가 있습니다.
  편의를 위해 제거하지 마세요.
- 하루 발행 수와 간격은 네이버가 정한 값이 아니라 **이 앱의 자체 브레이크**입니다.
  네이버의 실제 한도는 공개돼 있지 않으니 보수적으로 두는 편이 안전합니다.
- **검색으로 가져온 사진은 저작권 분쟁 소지가 있습니다.** 워터마크·인물 걸러내기가 있어도
  사용 권리를 보장하지는 않습니다. 상업적으로 쓰신다면 **AI 가 그리기** 나 **내 사진 쓰기** 가 안전합니다.
- **국내 인물 사진은 초상권 위험**이 있어 애매하면 배제하는 쪽으로 판정합니다.
- 수집한 자료는 참고용입니다. 글은 새로 씁니다.

## 만드는 사람을 위한 메모

```
npm run verify     # 계정 없이 확인 가능한 검증 전부
npm run harness    # 에디터 입력 순서만 따로 (로컬 하네스)
npm run typecheck
```

- AI 호출은 `claude -p --output-format json` 으로만 합니다(구독요금제로 돌리기 위해).
  `@anthropic-ai/sdk` 를 쓰지 마세요. 프롬프트는 반드시 stdin 으로 넘깁니다.
- 네이버 셀렉터는 `lib/scrape/selectors.ts` **한 파일**에만 있습니다.
  값이 안 맞으면 지우지 말고 **후보 배열 앞에 추가**하세요 — 계정·시점·A/B 에 따라 마크업이 다릅니다.
- 코드의 `⚠️` 주석은 실제로 겪은 함정의 기록입니다. 이유를 읽지 않고 정리하면 되살아납니다.
- 모든 산출물(DB·로그인 정보·사진·스크린샷)은 `./data/` 안에만 있습니다. 지우면 초기화됩니다.
- ⚠️ `npm run build` 를 돌린 뒤 `npm run dev` 를 그대로 띄우면 `.next` 의 프로덕션 산출물과
  충돌해 모든 요청이 **500** 이 됩니다. 전환할 때는 `.next` 를 지우세요.
  (dev 서버를 두 개 띄운 채 `.next` 를 지워도 같은 증상이 납니다.)
- 로그인 후 처음 할 일: `npm run probe` — 살아 있는 에디터를 3단계로 실측해
  `data/dumps/` 에 덤프와 스크린샷을 남깁니다. 셀렉터가 안 맞으면 이 결과를 근거로
  `selectors.ts` 후보 배열 **앞에** 새 값을 추가하세요.
